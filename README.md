# نظام الفواتير – تطبيق أندرويد

فواتير وعروض أسعار وسندات قبض وأذونات تسليم لشركات الشاحنات والحديد والهيدروليك. PDF عربي/إنجليزي، مكتبة شعارات، سجل وتقارير، ويعمل بدون إنترنت.

- كل دفعة على فرع `main` تبني APK موقّع تلقائياً وتنشره في **Releases**.
- التحديث يُثبَّت فوق النسخة القديمة ويحافظ على البيانات (نفس مفتاح التوقيع).

من تطوير: حامد الدهاش
